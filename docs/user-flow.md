# User Flow

1. User opens the comparison page.
2. User creates a comparison project and describes what they want to decide.
3. User adds items manually, from text, links, screenshots, or files.
4. User reviews extracted item details in a flexible comparison table.
5. User requests an AI comparison summary.
6. App shows key differences, pros, cons, trade-offs, risks, and recommendations.
7. User saves, exports, or shares the comparison result.
