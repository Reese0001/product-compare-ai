# Compare Anything Requirements

## Goal

Build an AI-assisted comparison app that helps users compare any set of options: products, services, tools, plans, places, vendors, ideas, documents, or decisions.

## Core Features

- Add or import items for comparison.
- Support flexible item types instead of only products.
- Compare items side by side with dynamic criteria.
- Generate AI summaries, trade-offs, risks, and recommendations.
- Display supporting text, links, screenshots, files, or notes for each item.

## Success Criteria

- Users can understand differences between options quickly.
- AI output is concise, explainable, and based on provided item data.
- The app can adapt comparison criteria to the item type and user goal.
